### In production at Doctreen

About two years shipping medical AI that real clinicians used. I built LLM and RAG pipelines, vision-language pipelines for DICOM imaging, guardrails against prompt injection, and benchmarking infrastructure that compared multiple LLM providers stage by stage. I also built a TOON serialization layer that cut token usage by roughly 37 to 40 percent.
